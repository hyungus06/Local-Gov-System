# Local-Gov-System — 行政情報システム

> **Status:** 設計・試作段階（Draft v0.1）  
> **更新日:** 2026-10-22

## 概要

Local-Gov-System は、**日本の一般市（行政区を設置しない市）を想定した自治体向け行政業務システム**の個人開発プロジェクトです。

第一段階では、職員が使用する庁内システムとして**許認可申請の受付・審査・決裁・処理履歴管理**を実装します。その後、人事管理などの行政業務を追加し、複数の業務で共通利用できる認証・認可、ワークフロー、決裁、監査ログ等を段階的に整備します。

このプロジェクトは学習・研究を目的とした**模擬システム**であり、特定の自治体の公式システムではありません。

## 開発方針

- **バックエンドから実装する。** NestJS API・業務ルール・DB・テストを先に整備し、画面は後から追加します。
- **小さく実装し、段階的に拡張する。** 最初から全業務に対応する汎用エンジンは構築しません。
- **業務ロジックはバックエンドに集約する。** 画面側の検証だけで処理を確定させません。
- **業務ドメインを分離する。** 許認可・人事等の固有ルールと、共通機能を区別します。
- **履歴を残す。** 状態変更・決裁・重要なデータ更新には実行者と日時を記録します。
- **ドキュメントを実装に合わせて更新する。** 未決定事項は明示し、実装後に設計との相違を解消します。

## 対象範囲

| 段階    | 対象               | 主な機能                                                 | 状態     |
| ------- | ------------------ | -------------------------------------------------------- | -------- |
| Phase 1 | 許認可管理         | 申請登録、受付、審査、補正依頼、決裁、許可・不許可、履歴 | 計画中   |
| Phase 2 | 人事管理           | 職員情報、組織、所属、異動・発令履歴                     | 将来構想 |
| Phase 3 | 共通業務基盤の拡張 | 決裁経路、文書管理、通知、権限・監査機能の高度化         | 将来構想 |
| Phase 4 | その他の行政業務   | 新たな許認可・庁内業務の追加                             | 将来構想 |

初期の許認可モデルは **「公園内行為許可」** を参考にします。ただし、自治体ごとの条例・規則・運用の違いは簡略化し、実際の申請・許可には利用できません。

## 最初の開発目標（MVP）

### 先行：バックエンド MVP

1. 職員とロールを模擬データで登録し、認証・認可を検証できる。
2. 公園内行為許可の申請を API で登録・検索・参照できる。
3. 受付・審査・補正依頼・決裁・許可／不許可を API で処理できる。
4. 全ての重要な状態変更と処理履歴を永続化できる。
5. 権限外の操作、不正な状態遷移、同時更新を API と自動テストで検証できる。

### 後続：最小フロントエンド

- 静的 HTML と標準 JavaScript による申請一覧・詳細・登録・操作画面を用意する。
- `fetch()` で NestJS の JSON API と通信し、画面には結果のみ反映する。

初期段階では、窓口職員による申請情報の入力を想定します。**住民向けオンライン申請画面は MVP の対象外**です。
